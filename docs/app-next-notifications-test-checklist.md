# app-next 알림 읽기 전용 테스트 체크리스트

## 접속

기준 주소는 `127.0.0.1`만 사용한다.

```text
http://127.0.0.1:5173/app-next.html?appNext=on
```

## 탭 구조

- [ ] `계정 상태` 탭이 기존처럼 표시된다.
- [ ] `로그인 기기` 탭이 기존처럼 표시된다.
- [ ] `알림` 탭이 추가되어 있다.
- [ ] 탭 전환에 React Router가 필요하지 않다.
- [ ] 운영 정적 앱으로 자동 이동하지 않는다.

## 계정 상태별 처리

- [ ] loading 상태에서는 “불러오는 중” 계열 안내가 표시된다.
- [ ] signed out 상태에서는 로그인 필요 안내가 표시된다.
- [ ] active 상태에서는 알림 조회를 시도한다.
- [ ] active + workspace null 상태에서는 workspace 알림이 제외된다.
- [ ] pending 계정은 조회를 차단하거나 계정 상태 안내만 표시한다.
- [ ] rejected 계정은 조회를 차단한다.
- [ ] disabled 계정은 조회를 차단한다.
- [ ] error 상태에서도 자동 로그아웃되지 않는다.
- [ ] system_owner도 전체 알림이 아니라 본인 알림만 표시한다.

## 데이터 표시

- [ ] 알림 데이터가 없으면 `표시할 알림이 없습니다.`가 표시된다.
- [ ] 개인 알림 1개가 있으면 1개만 표시된다.
- [ ] 알림 여러 개는 최신순으로 표시된다.
- [ ] 최대 표시 개수는 50개다.
- [ ] 읽음 여부가 표시된다.
- [ ] 읽음 여부는 표시만 되고 수정되지 않는다.
- [ ] 알림 종류가 표시된다.
- [ ] 생성 시각이 표시된다.
- [ ] system/workspace/personal 구분이 표시된다.
- [ ] 긴 내용은 요약되어 표시된다.

## 조회 범위

- [ ] Firestore 조회는 `uid == 현재 uid` 조건으로 제한된다.
- [ ] 전체 `notifications` 컬렉션을 무조건 읽지 않는다.
- [ ] workspace가 있으면 현재 workspace 또는 workspace 없는 알림만 표시된다.
- [ ] workspace가 null이면 workspace 알림은 표시되지 않는다.
- [ ] 다른 사용자의 알림은 표시되지 않는다.

## 민감 정보

- [ ] 전체 UID가 표시되지 않는다.
- [ ] 전체 workspaceId가 표시되지 않는다.
- [ ] recipient UID 목록이 표시되지 않는다.
- [ ] 내부 문서 ID가 표시되지 않는다.
- [ ] `relatedId`가 표시되지 않는다.
- [ ] 토큰이 표시되지 않는다.
- [ ] 오류 stack이 표시되지 않는다.

## 네트워크 및 write 안전성

- [ ] `getDocs()` 기반 1회 조회만 수행한다.
- [ ] `onSnapshot` listener가 생성되지 않는다.
- [ ] `listener count: 0` 진단이 표시된다.
- [ ] 알림 탭 진입만으로 Firestore write가 발생하지 않는다.
- [ ] 알림 카드 클릭으로 Firestore write가 발생하지 않는다.
- [ ] 읽음 처리 요청이 발생하지 않는다.
- [ ] 삭제 요청이 발생하지 않는다.
- [ ] 새로고침 중에는 버튼이 비활성화되어 중복 요청을 막는다.
- [ ] 자동 `signOut`이 발생하지 않는다.
- [ ] legacy `src/context/AuthContext.tsx`가 mount되지 않는다.

## 오류 표시

- [ ] permission-denied 발생 시 `알림을 불러올 권한이 없습니다.`가 표시된다.
- [ ] 인덱스 오류 발생 시 `현재 조회에 필요한 인덱스가 준비되지 않았습니다.`가 표시된다.
- [ ] 기타 오류 발생 시 로그인 세션 유지 안내가 표시된다.
- [ ] 오류 원문, 프로젝트 ID, 내부 쿼리값은 화면에 표시되지 않는다.

## 회귀 확인

- [ ] `http://127.0.0.1:5173/` 운영 정적 앱이 기존처럼 열린다.
- [ ] `index.html`, `app.js?v=111`, 시간표 V111 동작이 변경되지 않았다.
- [ ] Firestore Rules, 인덱스, 실제 Firebase 데이터가 변경되지 않았다.
