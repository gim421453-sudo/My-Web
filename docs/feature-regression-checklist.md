# 기능 회귀 점검 체크리스트

작성일: 2026-07-21

용도: 운영 앱 주요 버그 수정 전후에 같은 순서로 확인한다. 실제 학생/개인정보 대신 테스트 계정과 데모 데이터만 사용한다.

## 공통 준비

- [ ] 통합 앱 `http://127.0.0.1:5173/` 접속
- [ ] 관리자 전용 앱 `http://127.0.0.1:5181/` 접속
- [ ] Firebase 설정 안내가 뜨지 않는지 확인
- [ ] 콘솔에 API 키, 전체 UID, 전체 이메일이 출력되지 않는지 확인
- [ ] 테스트 workspaceId가 의도한 workspace인지 마스킹 값으로 확인
- [ ] `system_owner`, `super_manager`, `manager`, `teacher`, `normal`, `viewer`, `print_account` 중 필요한 테스트 계정 준비

## 인증/세션

- [ ] 로그인하지 않은 상태에서 메인 화면 접근 시 로그인 화면 또는 제한 화면 표시
- [ ] 통합 앱 로그아웃 후 새로고침 시 자동 로그인 여부가 정책과 맞는지 확인
- [ ] 관리자 전용 앱은 브라우저 뒤로/앞으로 가기 후에도 명시 로그인 정책을 따르는지 확인
- [ ] 오너 계정은 기존 앱 로그인 유지
- [ ] Shadow Mode 결과가 CRITICAL 없이 WARNING 이하인지 확인
- [ ] 일반 계정은 자기 workspace 메뉴만 표시
- [ ] 승인 대기 계정은 보호 데이터 쿼리 없이 승인 대기 화면만 표시

- [ ] `manager`: 자기 workspace 사용자/학생 데이터 관리
- [ ] `teacher`: 수업/과제/출결/시험 관련 허용 범위 확인
- [ ] `normal`: 관리자/친구 상벌점/민감 관리자 메뉴 숨김
- [ ] `viewer`: 쓰기 버튼 없음
