# My Web 사용자 매뉴얼 초안

## 시작

개발 확인 주소는 `http://127.0.0.1:5173/`이다. 운영 정적 앱과 `/app-next.html`은 별도 entry다. 로그인·이메일 인증·workspace 상태가 준비되지 않으면 데이터 화면으로 이동하지 않는다.

## 기본 사용

- 대시보드: 일정, 공지, 급식, 과제, 시험, 포트폴리오 요약을 확인한다.
- 일정: `오늘 일정`, 전체 일정, 검색/필터, 상세보기와 기존 CRUD를 사용한다.
- 공지: 제목·출처·과목·중요도·날짜·내용을 확인한다. 서버 확인 전 성공으로 보지 않는다.
- 과목·교사: 참조 선택은 표시명으로 보고, 교사 담당 과목은 같은 문서 ID를 중복 선택하지 않는다.
- 수업 자료: 첨부는 파일명·형식·크기·상태만 확인한다. Drive 실제 저장은 아직 연결되지 않았다.
- 수업 기록·과제: 입력 필수 여부를 화면 안내에 따르고, 저장 성공 안내가 서버 확인 후인지 확인한다.
- 시험 일정: 예정/진행과 종료 탭을 사용한다. 취소는 종료와 별도 정책이다.
- 시간표: 일반 시간표, 프로그램 시간표, 빠른보기를 구분한다. 시간표 변경은 운영 검증 범위가 별도다.
- 검색/필터: 필터 변경 후 선택 대상과 workspace 범위를 확인한다.

## 계정과 권한

`system_owner`는 전역 역할이며 workspace role이 아니다. workspace가 없으면 계정은 유지되지만 workspace 데이터는 표시되지 않을 수 있다. viewer와 print_account는 읽기 전용을 기준으로 한다. 권한 오류가 나면 반복 클릭하지 말고 화면의 오류 code와 시간만 기록한다.

## 지원하지 않거나 확인 중인 기능

실제 Google Drive OAuth, NEIS 운영 연결, 카카오 알림톡, 수납·미납·결제, 시험 성적, OMR, 보고서/Print Center 고급 기능, 자동 백업·복구는 현재 사용 가능하다고 안내하지 않는다. 문제 발생 시 새로고침 전후, workspace 선택, Console의 민감정보 없는 오류 code를 기록한다.
