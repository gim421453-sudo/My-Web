## 오류 분류

| 분류 | 기록 기준 |
|---|---|
| P0 | 데이터 손실, false success, 권한 우회, 다른 workspace 혼입, 직접 식별자 노출, write gate 우회, 중복 저장 |
| P1 | 빠른 등록/빈 화면, 필터 enum, 수정 기준값, 보고서·인쇄 누락, 파일 링크, 빈 상태/오류 혼동 |
| P2 | 문구, camelCase/raw enum, 버튼 위치, 정렬 UI, 공백/깨짐 |
| HOLD | 현 단계에서 확정 또는 수정하지 않는 기존 보류 항목 |
| EXTERNAL | proxy, NEIS, Storage 등 외부 설정·서버 의존 |

## 주의

- Google popup COOP 경고는 로그인 성공 후 비치명 경고로 별도 기록한다.
- Firestore Listen 400은 기존 HOLD이며 이번 Audit의 수정 대상이 아니다.
- `permission-denied`, `resource-exhausted`, `server confirm` 실패는 성공으로 기록하지 않는다.
- 로그와 보고서에 UID, 이메일, 전체 workspaceId, documentId, token, API key를 적지 않는다.
