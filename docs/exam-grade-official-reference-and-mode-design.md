# 시험·성적 공식 참고 및 운영 모드 설계

## 기준

MY WEB은 학교 내부 평가 업무를 보조하는 관리 기능이다. NEIS와 동일한 시스템, 공식 NEIS 연동, 교육청 인증 시스템 또는 법적 전자결재 효력을 제공한다고 표시하지 않는다. 공식 NEIS 입력과 학교 규정에 따른 최종 확인은 별도로 필요하다.

## UI·데이터 반영

- 평가계획은 한국어 상태 선택지로 표시한다: 초안, 검토 요청, 검토 중, 승인, 반려, 확정, 폐기.
- 과목 → 평가계획 → 지필/수행 항목 → 성적 입력 순서를 유지한다.
- 성취도는 정책의 점수 구간으로 자동 미리보기만 제공하며, 학생별 직접 override와 자동 전체 재계산은 제공하지 않는다.
- 운영 모드는 `personal`, `school`, `academy`, `integrated_unconfigured` 중 하나이며 화면 구성만 바꾼다. 데이터 삭제·이동·변환은 하지 않는다.
- 내부 결재는 금전 결제가 아니며, 평가계획과 성적 관련 검토·승인 기록을 위한 최소 구조다.
- 첨부는 metadata-only다. File, Blob, base64, local path 및 Drive 업로드는 저장하지 않는다.

## 반영하지 않은 항목과 확인 필요사항

- 학교별 학업성적관리규정, 교육청별 세부 기준, 결시 처리 및 최종 성적 확정 규칙은 개별 학교의 최신 규정을 별도로 확인해야 한다.
- 공식 공개자료가 충분하지 않아 전국 공통 단일 Excel 양식은 확정하지 못했다.
- XLSX 읽기·쓰기는 기존 의존성 확인 전까지 제공하지 않으며 CSV만 지원한다.
- NEIS 공식 상세 사용자 설명서의 일부 공개 범위는 이번 확인에서 확정하지 못했다.
- 전자결재는 내부 업무 보조용이며 법적 전자결재 효력을 주장하지 않는다.
