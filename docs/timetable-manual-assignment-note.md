# 시간 지정 수동 교과과정 배정서 확인 메모

작성일: 2026-07-21

## 실제 코드 위치

- `app.js`의 `manualTimetableFormV29(setId)`

## 현재 기능

이 기능은 선택된 시간표 세트에 대해 요일, 교시, 과목, 선생님, 강의실, 시작 시간, 종료 시간을 직접 입력하여 `store.timetable`에 수업 배정을 추가하거나 같은 요일/교시의 기존 배정을 갱신한다.

저장 대상은 `store.timetable`이며, 기존 행이 있으면 같은 `setId + day + period` 기준으로 덮어쓴다.

## 의미 판정

현재 구현은 교육과정 문서 출력 기능이 아니라 **교시별 수동 수업 배정** 또는 **시간표 직접 편성** 기능에 가깝다.

## 이름 후보

- 수동 시간표 배정
- 교시별 수업 배정
- 시간표 직접 편성

## 이번 단계 처리

기능은 삭제하지 않았다. 운영 화면 이름 변경은 사용자가 최종 명칭을 선택한 뒤 적용하는 편이 안전하다.
