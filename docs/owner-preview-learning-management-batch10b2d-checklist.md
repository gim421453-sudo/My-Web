# Owner Preview Learning Management Batch 10B-2D Checklist

기준 주소: `http://127.0.0.1:5173/`

이 체크리스트는 수동 검증 전용입니다. 실제 데이터 일괄 변경, Rules 변경, 배포는 포함하지 않습니다.

## A. 교사 과목 중복 선택

- 교사 추가 화면에서 과목 하나를 선택한다.
- 선택한 과목이 chip으로 표시되고 select에서 비활성화되는지 확인한다.
- 같은 과목을 다시 추가할 수 없는지 확인한다.
- 이름은 같지만 문서 ID가 다른 과목은 각각 선택 가능한지 확인한다.

## B. 교사 Chip 제거와 재선택

- 기존 교사 수정 화면에서 담당 과목 chip이 복원되는지 확인한다.
- chip의 `제거`를 누른다.
- 해당 과목이 다시 선택 가능한지 확인한다.
- 저장 뒤 `subjectIds`가 중복 없이 배열로 유지되는지 확인한다.

## C. 기록부 첫 클릭 저장

- 기록부/세특 신규 추가 화면을 연다.
- 활동명만 입력하고 저장을 한 번 누른다.
- 메모나 다른 선택 입력란으로 초점이 이동하지 않는지 확인한다.
- 저장 중 상태 뒤 서버 확인 성공과 목록 갱신이 한 번만 일어나는지 확인한다.

## D. 기록부 선택 필드 공란

- 과목, 선생님, 학년, 본문, 메모를 비운 상태로 활동명만 입력한다.
- 저장이 가능한지 확인한다.
- 활동명이 비었을 때만 활동명 입력란에 `활동명을 입력해 주세요.` 오류가 표시되는지 확인한다.

## E. 기록부 중복 문서 방지

- 저장 버튼을 빠르게 두 번 누른다.
- 신규 문서가 한 건만 생성되는지 확인한다.
- 수정 화면의 기존 값과 첨부/링크 hydration이 유지되는지 확인한다.

## F. 첨부 상세 표시

- 수업 자료 상세보기를 연다.
- 각 첨부에 파일명, 사용자용 파일 형식, 읽기 쉬운 파일 크기, 상태가 분리되어 표시되는지 확인한다.
- 로컬 메타데이터 첨부에는 `이 기기에서 다시 선택해야 합니다.`가 표시되는지 확인한다.

## G. 첨부 내부 키 미노출

- 첨부 상세에 attachment ID, local key, 경로, 원시 MIME, 원시 bytes, JSON, Blob 값이 보이지 않는지 확인한다.
- 실제 Drive 링크가 있는 경우에만 `열기`가 보이는지 확인한다.

## H. 과거 시험 자동 분류

- 시험일이 어제인 시험을 시험 일정 화면에서 확인한다.
- `종료된 시험` 탭에만 표시되는지 확인한다.

## I. 오늘 종료시간 분류

- 오늘 날짜와 지난 종료 시간을 가진 시험이 종료 탭에 표시되는지 확인한다.
- 오늘 날짜와 미래 종료 시간을 가진 시험은 예정/진행 탭에 남는지 확인한다.

## J. 탭 중복 방지

- 미래 시험, 완료 상태 시험, 취소 상태 시험을 각각 확인한다.
- 완료 시험은 종료 탭, 취소 시험은 취소 정책에 따라 예정/진행 탭에 유지되는지 확인한다.
- 동일 시험이 두 탭에 동시에 표시되지 않는지 확인한다.

## K. 기존 기능 회귀

- 교사 담당 과목 제거 후 저장
- 과목 필수값 validation
- 과목/수업 자료 상세의 내부 식별자 미노출
- 기록부 수정 hydration
- 시험 연도와 날짜 validation
- 공지, 일정, 출결, 시간표 기본 기능
- Operational Safety와 Release Manifest 진단
