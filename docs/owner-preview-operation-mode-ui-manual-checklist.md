# Owner Preview 운영 모드 UI 수동 체크리스트

기준 캐시: `app.js?v=154`, `systemAdminService.js?v=15`, `examGradeService.js?v=2`

수동검증 전 상태는 PASS로 기록하지 않는다. 개발 서버는 사용자가 직접 실행한다.

## 학교 모드

- [ ] 대시보드 상단에 `학교 모드` badge와 학교 업무 안내가 표시된다.
- [ ] 학생 관리, 교사 관리, 시간표, 출결, 시험·성적, 기록부 메뉴가 표시된다.
- [ ] 학원 수납 기능이 실제 기능처럼 표시되지 않는다.
- [ ] 공지, 일정, 자료, 포트폴리오 등 공통 메뉴가 유지된다.
- [ ] system_owner에게 최고관리자 콘솔이 유지된다.

## 접근 제어

- [ ] 현재 모드에서 허용된 메뉴가 정상 진입한다.
- [ ] 제한된 페이지를 직접 호출하면 안내 후 대시보드로 이동한다.
- [ ] 제한된 페이지에서 빈 화면, 화면 멈춤, 데이터 쓰기가 발생하지 않는다.
- [ ] 기존 role/workspace 권한 제한이 그대로 적용된다.

## 변경 이력

- [ ] 운영 모드 화면 진입만으로 변경 이력이 자동 표시되지 않는다.
- [ ] `변경 이력 보기`를 누른 뒤에만 이력이 표시된다.
- [ ] 변경 시각, 변경자, 이전 모드, 새 모드, 사유, 서버 확인 상태가 표시된다.
- [ ] UID와 전체 이메일이 노출되지 않는다.

## 반복 안정성

- [ ] 같은 메뉴를 10회 눌러도 화면이 멈추지 않는다.
- [ ] 대시보드를 10회 열어도 메뉴가 중복되지 않는다.
- [ ] 운영 모드 설정 화면을 5회 왕복해도 history 자동 조회가 없다.
- [ ] listener 수가 증가하지 않는다.
- [ ] `window.PMModeDiagnostics?.snapshot?.()` 호출이 render/read를 발생시키지 않는다.
- [ ] `modeServerLoadCount`가 같은 workspace에서 최대 1이다.
- [ ] Console 오류가 없다.

## 모드별 후속 검증

- [ ] 개인 모드에서 개인 일정·학습·성적 중심 메뉴가 표시된다.
- [ ] 학원 모드에서 학생·강사·수업·출결 중심 메뉴가 표시된다.
- [ ] 학원 수납·미납·영수증은 준비 중 안내만 표시된다.
- [ ] 미설정 모드에서는 공통 메뉴만 보이고 system_owner에게만 설정 바로가기가 표시된다.

## 독립 관리자 사이트

기준 주소: `http://127.0.0.1:5181/`

- [ ] `pm-env.js?v=1`에서 `PM_APP_TARGET`이 `admin-standalone`이다.
- [ ] `admin-standalone`이 운영 모드 값으로 표시되거나 저장되지 않는다.
- [ ] 선택한 workspace의 운영 모드가 메인 앱과 동일하다.
- [ ] 일반 사용자 업무 메뉴는 왼쪽 메뉴에 표시되지 않고 system_owner 관리 진입점만 유지된다.
- [ ] 시스템 상태, workspace 관리, 운영 모드, 사용자·권한, 승인, 시스템 공지, 점검, 감사 로그, API 연동, 운영 진단, 보안 점검 영역이 유지된다.
- [ ] 학교 모드에서 학생·교사·학년·반·과목·시간표·출결·시험·성적 관리 상태가 표시된다.
- [ ] 학원 모드에서 학생·반·수업·강사·출결 관리 상태가 표시되고 학교 전용 기능은 표시되지 않는다.
- [ ] 개인 모드에서 개인 일정·학습·기록·성적·포트폴리오 관리 상태가 표시된다.
- [ ] 미설정 모드에서 `운영 모드가 아직 설정되지 않았습니다.` 안내와 설정 버튼이 표시된다.
- [ ] 운영 모드 설정은 메인 앱과 같은 `systemAdminService` 처리 결과를 사용한다.
- [ ] 운영 모드 화면 진입만으로 변경 이력이 조회되지 않는다.
- [ ] 변경 이력의 시각·변경자·이전/새 모드·사유·서버 확인 상태가 메인 앱과 같은 형식이다.
- [ ] UID, 전체 이메일, 전체 workspace ID가 표시되지 않는다.
- [ ] 운영 모드 변경 후 새로고침하면 메인 앱과 독립 관리자 사이트가 같은 값을 표시한다.
- [ ] Console 오류가 없고 화면이 멈추지 않는다.
