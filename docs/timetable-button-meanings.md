# Timetable Button Meanings Draft

현재 개발 상태 기준 초안입니다. 최종 사용자 매뉴얼이 아니라 시간표 기능 안정화 중 버튼 의미를 헷갈리지 않도록 정리한 문서입니다.

## 셀 동작

| 동작 | 의미 |
| --- | --- |
| 빈 셀 클릭 | 새 수업 등록 dialog를 엽니다. |
| 수업이 있는 셀 클릭 | 기존 수업 수정 dialog를 엽니다. |
| 수업 수정 저장 | 같은 `setId + day + period`의 기존 row를 갱신합니다. 신규 중복 row를 만들지 않습니다. |
| 이 수업 삭제 | 선택한 정확한 수업 row 한 건만 삭제합니다. 교시 전체나 시간표 전체를 삭제하지 않습니다. |

## 삭제 범위

| 버튼 | 삭제 범위 | 유지되는 것 |
| --- | --- | --- |
| 이 수업 삭제 | 선택한 수업 row 1건 | 다른 요일, 다른 교시, 다른 시간표, periodTimes, timetableSets |
| 현재 교시 제거 | 현재 선택된 시간표에서 해당 교시의 수업 배정 | 공통 교시 시간, 다른 시간표 |
| 선택 시간표 비우기 | 현재 선택한 시간표의 수업 배정 전체 | 시간표 이름, 교시 시간, 다른 시간표 |
| 현재 시간표 삭제 | 현재 선택한 timetableSet과 그 set의 수업 배정 | 다른 시간표, 공통 교시 시간 |
| 공통 교시 시간 삭제 | `periodTimes` 공통 시간 설정 | 시간표 목록, 수업 배정 |

## 빠른보기

| 모드 | 의미 |
| --- | --- |
| 목록형 빠른보기 | 선택 시간표의 수업을 요일/교시 목록으로 보여줍니다. |
| 시간표표 빠른보기 | 선택 시간표를 표 형태로 보여줍니다. |

빠른보기는 일반 시간표와 같은 active timetable helper를 사용해야 합니다. 삭제된 시간표나 orphan row는 표시하지 않습니다.

## visiblePeriodCount

`visiblePeriodCount`는 시간표별로 몇 교시까지 보여줄지를 저장하는 표시 범위입니다. 개별 수업 삭제로 변경되면 안 됩니다.

## 저장 원칙

렌더, 빠른보기 열기, 탭 진입, 단순 선택 변경은 Firestore 저장 예약을 만들면 안 됩니다. 사용자 수정, 추가, 삭제, 이름 변경 같은 명시적 저장 동작만 저장 예약 후보입니다.
